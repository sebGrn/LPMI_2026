Tracker Cryptomonnaies Application développée par MOUSSA

Application Angular réalisée dans le cadre du cours « Technologies pour le web - Framework Angular » (Licence Professionnelle LPMI, Université de Bourgogne).

Elle permet de consulter une liste de cryptomonnaies (Bitcoin, Ethereum, Solana, Cardano), d'afficher le détail de chacune et de mettre une crypto en avant sur la page d'accueil. Les données sont fournies par un serveur JSON (json-server).
