## Catalogue Films & Séries

Application Angular de découverte et de recommandation de films et de séries. Elle comprend un catalogue filtrable, des fiches détaillées, des commentaires enregistrés localement et un chatbot de recommandation.

### Lancer le projet

Depuis le dossier du dépôt :

```bash
cd catalogue-films-series
npm install
npm start
```

Ouvrez ensuite <http://localhost:4200>. Le guide visiteur et développeur complet se trouve dans le [README de l’application](./catalogue-films-series/README.md).
